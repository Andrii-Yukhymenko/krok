# Крок / Daily Step Map

Україномовний MVP планувальника пішохідних прогулянок із встановленням як PWA.

## Розробка у WSL

Node.js >= 22.13 (у поточній WSL доступний Node 24 через nvm).

```sh
cd /home/soda/daily-step-map
nvm use 24
npm ci
npm run dev -- --host 0.0.0.0
```

Відкрити http://localhost:3000. Для GPS і PWA на телефоні потрібен HTTPS; звичайна LAN-адреса через HTTP не підходить. Вбудований браузер може не підтримувати встановлення — використовуйте Safari або Chrome.

```sh
npm test
npm run typecheck
npm run lint
npm run build
npm start -- --ip 0.0.0.0
```

Service worker реєструється тільки в production. Збірка додає локальні JS/CSS у precache. Перевірка реального встановлення на iOS/Android ще потребує пристрою користувача.

## Що працює

- Старт із GPS, прицілу на карті з окремим підтвердженням або координат; демонстраційний старт у Києві позначений явно.
- До точки — автоматична побудова після натискання; до 18 проміжних точок — після підтвердження.
- Ескіз пальцем/мишкою з окремим режимом малювання та поверненням до переміщення карти. Лінія перетворюється на до 18 опорних точок, які маршрутизатор прив'язує до пішохідної мережі. Це наближення, не точне map matching.
- Повернення тією самою геометрією: дистанція та час подвоюються.
- Пропозиція замкненої прогулянки: до трьох послідовних спроб із коригуванням радіуса. Близькість до цілі не гарантована; різниця показується завжди. Маршрут може містити повторні ділянки.
- Зріст із автоматичною приблизною оцінкою кроку, денна ціль, повзунок пройдених кроків на головній сторінці та точне введення в налаштуваннях. Enter або «Готово» зберігає форму; порожні поля цілі та пройдених кроків означають нуль. Налаштування локальні; координати не зберігаються.
- Старт не встановлюється натисканням на карту: пересуньте її під приціл і натисніть «Підтвердити старт тут». Клавіатура: стрілки для пересування карти, Tab та Enter для підтвердження. Вибір точок маршруту натисканням збережений.

## Архітектура та межі MVP

React + TypeScript, Leaflet, Vinext/Vite. Немає власного API чи бази даних. Компоненти карти, стан, геометрія, генерація кандидатів і підрахунок кроків працюють у браузері. Формула: `кроки = округлення(метри × 100 / довжина_кроку_см)`.

Маршрути реальними дорогами розраховує **зовнішній Valhalla**, профіль `pedestrian`. Адреса змінюється build-time змінною `NEXT_PUBLIC_ROUTING_URL`. Це публічний демонстраційний сервіс із fair-use обмеженнями, без SLA. Перед широким запуском потрібен власний інстанс або провайдер із відповідними умовами. Усі запити йдуть безпосередньо з браузера; координати бачить провайдер. Маршрут ділиться на запити по максимум 10 точок з однією спільною точкою на межі. Всі частини мають успішно побудуватись і з’єднатись, перш ніж показується результат. Таймаут одного запиту — 25 секунд, не більше одного запиту приблизно на секунду; пошук можна скасувати. При помилці немає підміни маршруту прямою лінією.

Карта — стандартні тайли OpenStreetMap із видимою атрибуцією. Не виконується попереднє масове завантаження або офлайн-кешування тайлів. Офлайн доступна оболонка й налаштування після успішного встановлення service worker, але для нових маршрутів і карти потрібна мережа.

Не є навігатором або крокоміром: немає фонового трекінгу, автоматичного підрахунку фактичних кроків, перевірки перекриттів або актуальних умов проходу. Точність залежить від OSM і довжини кроку. Час береться з маршрутизатора для ходьби близько 4.8 км/год.

## Наступні кроки після польового тесту

1. Калібрування кроку за реальною прогулянкою та зручніше редагування точок.
2. Оцінка якості ескізів і заміна семплювання на повноцінне map matching за потреби.
3. Вибір району для локального графа й маршрутизації у Web Worker/WASM, якщо потрібні повністю клієнтські обчислення.
4. Переваги стежок, парків, сходів та покриття — після перевірки наявності даних у потрібному місті.

## Оцінка за зростом

Довжина одного кроку оцінюється як `зріст × 0.41` з округленням до 0.1 см. Це обрана приблизна середина діапазону 0.37–0.45, який [наводить Omron](https://www.faq.healthcare.omron.co.jp/faq/show/4195?site_domain=jp), а не персонально виміряний крок. Стать, вага та вік для цієї простої моделі не потрібні. Початковий зріст 175 см потрібно замінити власним. Старе значення stride не використовується для вигадування зросту; ціль і сьогоднішні кроки зберігаються при переході.
